# Instagram Followback Checker

A minimal, front-end-only tool to check who doesn't follow you back on Instagram. All calculations run locally in your browser—no data is uploaded or saved.

## Usage

1. **Export Instagram Data**: Go to Instagram → **Settings** → **Your activity** → **Download your information** → select **Followers and following** in **JSON** format.
2. **Upload Files**: Drop your exported `followers_1.json` (supports multiple files) and `following.json` into the page.
3. **Compare**: Instantly view accounts that don't follow you back, accounts you don't follow back, and mutual followers.

## Hosting

Ready for [GitHub Pages](https://pages.github.com/). In your GitHub repo, go to **Settings → Pages** and select **Deploy from a branch** (`main` / root).
