Don’t have your export yet?
  1. Open Accounts Center → Your information and permissions → Export your information (in the app: Profile → ☰ → Accounts Center).
  2. Tap Create export, pick your Instagram account, then Export to device.
  3. Under Customize information, clear everything except Followers and following. That keeps the file tiny and fast.
  4. Set Date range to All time. The default is only the last year, which gives you wrong results.
  5. Format can be JSON or HTML. Either works. Start the export.
  6. Instagram emails you when it’s ready, usually within minutes. Download the zip and drop it here. No need to unzip it.
